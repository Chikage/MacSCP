# 验证记录

验证日期：2026-10-02。运行环境：Apple Silicon、macOS 27.0.1、Apple Swift 6.4。应用最低部署目标为 macOS 14；尚未在 macOS 14 的独立设备上运行验证。

## 自动化

`Scripts/test_ssh.sh` 在 127.0.0.1 的随机高端口启动临时 sshd，使用现场生成的 ED25519 服务器和客户端密钥，然后运行全部 Swift Testing 用例。13 项测试、17 组用例通过。

- SFTP 包大小、大端整数、UTF-8、截断数据与非法请求输入。
- Shell 单引号转义，主机选项注入与路径穿越拒绝。
- 两种协议均测试中文、空格、单引号、美元符号、Shell 元字符、零字节文件、隐藏文件和空目录。
- 两种协议均测试递归上传下载、同名跳过、替换提交及文件权限保留。
- 目录创建、重命名、删除和目标符号链接保护。
- 停滞通道取消：测试运行约 0.15 秒返回，测试上限 2 秒。
- 模拟下载中断：原目标内容保持完整，临时下载文件清理。
- 实际 SSH 密钥认证、SFTP/SCP 往返、远程删除。
- 变更的主机密钥拒绝；主连接断开后 slave 不另建连接。

没有向公网服务器发送数据，没有修改系统「远程登录」配置。测试结束会清理临时 sshd、密钥和文件。

## 界面操作

在打包的 `.app` 中实际操作并验证：本地浏览、已保存站点连接、文件选择、上传确认、上传完成后的列表刷新、目标目录跳转、下载确认和下载完成。下载文件经 `cmp` 与源文件比较一致。浅色与深色模式均检查过双栏、队列、表单和文字布局。

另外用临时加密私钥发起真实 SSH 登录，在独立认证助手输入测试口令，服务器返回 `authentication verified`。测试未保存口令到钥匙串。真实服务器密码登录、多因素认证和钥匙串持久保存尚未进行实机验证。

启动检查发现 `FileManager.attributesOfItem` 读取扩展属性可能等待云盘供应商，已改为 `lstat` 仅读取元数据；复查后本地目录正常显示。认证助手增加完整的 AppKit 启动流程、独立 bundle 标识和 modal runloop 取消检测。

## 构建和分发

Release 编译通过。DMG 镜像校验、只读挂载后签名验证、包内二进制比对通过；ZIP 解压后签名验证及源码 ZIP 完整性检查通过。主程序和认证助手均仅含 arm64。新版 macOS 使用 `diskutil image` 打包，旧版保留 `hdiutil` 兼容路径。

编译启用 Swift 6 严格并发及 `-warnings-as-errors`。打包脚本分别验证主应用和认证助手的 `lipo -archs` 结果仅为 arm64，并执行 `codesign --verify --deep --strict`。

采用 ad-hoc 签名；没有 Apple Developer ID 签名或公证。尚未对公网网络抖动、大规模目录、所有 Unix 服务端或长时间传输做兼容性矩阵验证。SwiftLint/Periphery 在本机未安装；本次进行了编译器检查、针对性源码检查和运行测试。
